## Ejecutar localmente

Se puede abrir `index.html` directamente en el navegador o usar **Live Server** desde VS Code. No es necesario compilar.

Otra opción, si tienes Python instalado:

```sh
python -m http.server 8080
```

Abrir `http://localhost:8080`. Las páginas secundarias usan rutas relativas y funcionan también sin servidor.

## Desplegar en Vercel

Importar este repositorio, seleccionar el preset **Other**, dejar vacíos los comandos de instalación y compilación, y usar la raíz del repositorio como directorio de salida (`.` si Vercel solicita un valor). Publicar como sitio estático. No necesita variables de entorno, API keys ni servicios externos.

El trabajo local no incluye publicación, cambios remotos, commits ni push.
